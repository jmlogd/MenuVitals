# Changelog

## Unreleased

- Network speeds appear in smaller type as a download/upload pair, such as `39KB/29KB`. Click the readings for full rates per second.

## 1.0.1 (2026-11-19)

- Fixed menu bar movement when CPU or memory readings gain a digit. Download and upload readings now have separate fixed-width columns so a change in one direction keeps the other arrow in place.
- Placed readings directly beside their icons and shortened network speeds in the menu bar (for example, ↓26K for 26 KB/s). Click for the full units.

## 1.0.0 (2026-11-19)

- Added live CPU, memory, and network readings with a click-to-open summary.
- Added per-metric settings, light and dark menu bar support, and optional launch at login.
